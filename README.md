# C++五子棋项目

## 简介
这是C++程序设计课程的大作业，制作人为Sjk1949，内容是一个可以用终端显示的五子棋程序，支持人人对战，人机对战，机机对战模式，并实现了非阻塞式刷新以及恒定帧率运行，内置菜单，计时器等必备组件，并支持悔棋功能。

这个项目的主要创新点和贡献在于：
- 实现了非阻塞式输入，程序不需要等待用户的输入来进行下一步操作，而可以给用户输入即时的反馈，程序依托这一点实现了计时器的显示，菜单的键盘选择等功能

- 实现了应用层，逻辑层，显示层的解耦，因此可以在开始菜单，五子棋主程序，结算画面等不同场景来回切换，并且让图形显示独立于游戏逻辑

- 实现了游戏主循环，并可以以恒定帧率运行，实现游戏画面的每帧刷新，并实现了在用终端显示的限制下刷新画面时基本不出现频闪现象

- 实现了跨平台(Windows/Linux)兼容，主要是在键盘输入事件，以及UI显示方面的兼容

## 编译
### Release版本
```bash
g++ -std=c++17 -O2 -DNDEBUG -Iinclude src/core/*.cpp src/ai/*.cpp src/input/*.cpp src/player/*.cpp src/ui/*.cpp src/ui/backend/*.cpp src/utils/*.cpp src/app/*.cpp src/command/*.cpp src/task/*.cpp src/menu/*.cpp -o GobangCpp.exe
```

## 运行
编译后执行以下命令
```bash
./GobangCpp.exe
```

- **更好的UI和交互** ，目前的UI受到终端界面的限制，在显示交互上存在一些不可避免的不足，在后续可以用图形化显示，并用鼠标点击移动进行交互，当然这已经在课程内容范围之外不提
